# Agent Operating Rules v2

## Rule 1 — Read The Architect Review

Every agent must read `.ai-swarm/ARCHITECT_REVIEW_REPORT.md` before work.

## Rule 2 — Wire Existing Code First

Agents must first check whether the repo already contains the required code. If yes, wire/refactor before rebuilding.

## Rule 3 — Stay In Scope

Each agent works only on assigned repo/files unless work packet allows cross-repo changes.

## Rule 4 — Update Reports

Every agent updates its report before stopping.

## Rule 5 — Produce Proof

No work is complete without proof.

## Rule 6 — Do Not Merge Own Work

Only the Integrator merges.

## Rule 7 — Respect Service Boundaries

LiNKaios controls execution. LiNKbrain stores memory/audit. LinkSkills governs capabilities. LiNKautowork executes deterministic workflows. LiNKbot reasons and delegates.

## Rule 8 — Stub Blockers

If CRM, Plane, preview publishing, or a third-party service blocks the 7-day sprint, create an MVO stub and record the real integration in backlog.

## Rule 9 — Do Not Start Legal

LEXOS remains separate until WebsiteFactory MVO works.

## Rule 10 — Record Decisions

All significant decisions go to `DECISIONS.md`.

## Rule 11 — Day-1 Decisions Are Binding

CRM, Plane, preview, Supabase, OpenClaw source, model routing, and template source must be frozen early.

## Rule 12 — Working Flow Wins

A working lead-to-preview-site flow is the priority.
