# LiNKtrend Imported Skills Policy

The skills in this folder were originally selected for the LEXOS repo but are useful for the broader LiNKtrend ecosystem build.

They are now governed by the LiNKtrend ecosystem rules and `.ai-swarm/` work-packet system.

## Use These Skills For

- architecture review
- repo archaeology
- database/schema design
- API patterns
- Node/Next.js best practices
- frontend implementation
- Tailwind/shadcn UI work
- testing and validation
- web app testing
- systematic debugging
- lint/type checks
- code review
- vulnerability scanning
- documentation
- shell/Docker work
- parallel-agent planning

## Do Not Use These Skills To

- bypass `.ai-swarm/` work packets
- modify unrelated repos
- replace architecture decisions
- invent new frameworks without approval
- ignore service boundaries
- remove audit, memory, capability-lease, or trace requirements

## Current Ecosystem Boundaries

- LiNKaios owns execution control, tenant/plugin/work/bot orchestration, and dashboard.
- LiNKbrain owns memory, event ledger, audit union, context assembly, and learning.
- LinkSkills owns capability leases, capability catalog, side-effect governance, run ledger, and skill certification.
- LiNKautowork owns deterministic workflow execution through n8n gateway.
- LinkBot owns role-bound reasoning/session/runtime adapter behavior.
