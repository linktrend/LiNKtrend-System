# LEXOS LinkBot roles — contracts

Declarative YAML contracts for `LexosRoleIdSchema` live in `./contracts/*.contract.yaml`.

- LinkBot executes judgment-heavy steps only; deterministic automation belongs to LiNKautowork.
- LiNKbrain owns durable memory objects, audit envelopes, and context assembly retrieval.
- LinkSkills grants capability leases; every storage, extraction, generation, research, or stub-write path must attach recorded lease identifiers.
