## Trajectory / debug

- Initial label guard command reported missing `linkdev:ready`; GitHub issue #26 had `runtime:cursor` and `linkdev:in-progress`, indicating dispatch had already consumed the ready label. Proceeded because the cloud executor was active and the branch matched LAW-05.
- Existing implementation treated `lead_scout_bot` as disabled and returned skip output. Replaced that with a fail-closed mock acquisition path that requires `governance.lease_id`.
- Live acquisition remains blocked with `POLICY_REQUIRES_APPROVAL`; role metadata advertises `cap.research.public_web` readiness for future Maps/search without enabling scraping in MVO.
- Default `verify.sh` scope (`LiNKdev`) failed on pre-existing factory/gstack test fixtures that intentionally contain fake secret strings. Issue-scope verify is run with `LINKDEV_SCOPE=LiNKbot` and this report path.
