_Status: implemented — executor proof pending reviewer_

**Principal ref:** PPD §3 progressive disclosure; LiNKguard IP

## Summary

Implemented progressive skill disclosure and worker residue boundaries across LinkSkills and LiNKbot:

- LinkSkills rejects full-corpus skill disclosure and oversized skill batches before lease lookup.
- LiNKbot runtime exposes a lease-scoped `discloseSkills` path for just-in-time skill fragments.
- Bot sessions store only disclosure token/manifest/fragment-hash refs, then scrub those refs during cleanup.
