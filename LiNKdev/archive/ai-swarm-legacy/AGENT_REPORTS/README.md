# Agent Reports

Agent reports are historical proof logs. They may contain old paths, old branch names, or pre-cleanup terms such as `plugins/vertical`, `LiNKbot/runtime-adapters/openclaw/bot-runtime`, `vertical plugin`, and `capability plugin`.

Do not use old report paths as current implementation instructions. For new work, use:

- `docs/architecture/repo-architecture-target.md`
- `docs/architecture/system-completion-targets.md`
- active `.ai-swarm/WORK_PACKETS/`
- active `.ai-swarm/AGENT_PROMPTS/`

When adding a new report, use current terms:

- `module`, not `vertical plugin`
- `capability connector`, not `capability plugin`
- `LiNKbot`
- `LiNKbrain`
