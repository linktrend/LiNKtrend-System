# LiNKautowork Templates

This folder contains declarative workflow template metadata used by the LiNKautowork gateway.

It is not the full n8n fork. The full self-hosted n8n fork lives at `/Users/linktrend/Projects/LiNKautowork`.

Files here describe handles, versions, lease requirements, source type, tags, and supported environments so LiNKaios, LinkSkills, LiNKautowork, and LiNKbrain can agree on workflow identity and audit behavior.

Current files:

- `schema.json`: JSON schema for workflow template declarations.
- `websitefactory-render.v1.json`: historical WebsiteFactory render template declaration.
- `websitefactory-render.v2.json`: current LinkSites / WebsiteFactory v2 render template declaration.
